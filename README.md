# Jacob's Inventory 🎮

A tiny, retro birthday adventure.

## How it works

- `index.html` — the inventory screen itself
- `introverted.html`, `intuitive.html`, `thinking.html`, `perceiving.html` — one per NFC tag/item tied to that trait
- `404.html` — what you see if you get lost
